This directory holds historical or superseded docs that are kept for provenance
but are no longer load-bearing.

## Policy

When a doc here is referenced by a current doc (CLAUDE*.md / ARCHITECTURE.md /
README.md), the reference must be updated to point at the live successor — or
removed entirely if the archived doc was the last reference. Archived docs are
not part of the live navigation tree.
