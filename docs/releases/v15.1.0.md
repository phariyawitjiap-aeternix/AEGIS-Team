# AEGIS v15.1.0 Release Notes

**Released**: 2026-05-23
**Scope**: 8 sprints + 1 learning + 2 fix-ups across 2 calendar days
**Driver**: Contra-Thai post-mortem (2026-05-20) — surfaced the verified-vs-produced bug class that drove the entire arc
**PRs**: #191 → #200

## Headline

AEGIS shifts from "ambitious framework that might oversell" to **"honest framework with enforceable contracts."** Coverage screen at intake, verified-vs-produced gates at every chain link, auto-fire research probe-gate, cross-session awareness via `claude agents` CLI, and an upgrade-sweep that finally kills stale-file accumulation in downstream.

Also: a strategic lean pass — `docs/AEGIS_VS_NATIVE_CC.md` makes positioning explicit; redundant duplicates (`mt cwd`, `mt run`, v9-era worktree tools) deleted; future lean passes propagate automatically via upgrade-sweep.

### Cross-session awareness (v15-22)

`tools/aegis-claude-agents.sh` wraps `claude agents --json` with 1-sec cache + graceful fallback. `mt sessions` merges multi-tenant registry with live session JSON. `/aegis-start` Step 2.7 warns about: (a) another CC session at same cwd (brain-write race risk), (b) idle session > 1h elsewhere (forgotten `/aegis-handoff`).

### Registry hygiene (v15-23)

`mt unregister <name>` + `mt prune [--dry-run]`. No more hand-editing `~/.aegis-plus/projects.yaml` to remove stale entries.

### Lean pass (v15-24 → v15-25)

- `docs/AEGIS_VS_NATIVE_CC.md` — authoritative positioning. What native CC owns vs what AEGIS uniquely adds.
- v9-era obsolete planning docs archived: `mcp-server-architecture.md`, `plugin-architecture.md`, `migration-ga-strategy.md`, `schedule-toolsearch-consolidation.md`.
- `mt cwd` + `mt run` subcommands deleted — native `claude --cwd "$(mt where <name>)" <args>` replaces them.
- `aegis-worktree-gc.sh` + `aegis-merge-worktree.sh` (464 LOC) archived — native `isolation: "worktree"` supersedes.
- Cwd-integration concepts: 3 paths → 1 canonical recipe.

### Upgrade-sweep (v15-26)

`install.sh --upgrade` now sweeps framework files that source has removed. Stale tools/skills/refs/hooks/agents/commands move to `${BACKUP_DIR}/swept/<rel-path>/`. Closes the "additive-only --upgrade" bug class.

**Real-world impact**: First run after v15-26 merged cleaned **122 stale files** across 7 downstream projects — accumulated cruft from multiple lean passes that hadn't propagated.

AEGIS no longer competes on infrastructure — it ships discipline, honesty, and persona content.

## Upgrade instructions

For projects already running v15.0:

```bash
cd <your-project>
bash <(curl -sL https://raw.githubusercontent.com/phariyawitjiap-aeternix/AEGIS-Team/main/install-remote.sh) --upgrade
```

The upgrade-sweep will automatically clean any stale framework files. Backup retained in `_aegis-backup-<ts>/swept/`.

For fresh installs, same recipe without `--upgrade`.
