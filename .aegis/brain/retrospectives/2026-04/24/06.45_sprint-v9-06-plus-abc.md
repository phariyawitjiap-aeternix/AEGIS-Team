## What went well

1. **Continuous execution**: A -> B -> C chained without pausing. All 3 PRs
   merged in sequence. No MBP violations (no questions asked to human).

2. **Pronoun fix batched efficiently**: grep found 4 files, fixed in one
   commit before sprint opened. Clean scoping.

3. **flock portability**: Correctly detected macOS lacks flock(1) and used
   Python fcntl instead. No platform-specific branches needed.

4. **Policy audit tool is genuinely useful**: 227 claims scanned, 20.3%
   coverage. The 79.7% unmatched is not a bug -- it correctly surfaces
   behavioral constraints that lack automated enforcement. This is exactly
   the "policy-without-test" bug class the user identified.

## What could improve

1. **JSON serialization in SDK checker**: First attempt used space-split
   for evidence fields, which concatenated everything. Fixed with tab-delimited
   temp file approach. Lesson: always use structured serialization for
   multi-word fields in shell scripts.

2. **Team chat --msg vs --message**: Loop harness used wrong flag name.
   Lesson: always check tool usage examples before calling.

3. **Playbook could use more examples**: Currently has one golden path
   (React). Future sessions could add Python/Django, Go, Rust walkthroughs.

## Lessons

1. fcntl.flock is the portable answer when flock(1) is unavailable on macOS
2. Policy claims without automated enforcement are the dominant gap in AEGIS
3. ADRs that document "blocked on external dependency" with a concrete
   integration plan prevent scope drift while preserving forward progress
4. Application playbooks should lead with the minimal setup, not the full
   enterprise configuration
5. v9 terminal declaration + v10 open-ended framing correctly separates
   "framework building" from "framework using"
